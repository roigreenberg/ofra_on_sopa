# עפרה על הספה (Ofra on the Sofa)

ארכיון קהילתי דיגיטלי המתעד את משפחות המייסדים והוותיקים של היישוב עפרה, מבוסס על תערוכת הדיוקנאות בסטודיו של ברוך גרינברג.

## 📁 מבנה הפרויקט

```text
├── index.html          # קובץ האתר הראשי (פועל עצמאית גם כ-Single File וגם בשרת)
├── template.html       # תבנית המקור לעיצוב ולוגיקה
├── data.json           # מאגר המידע המובנה של כל 68 המשפחות (ניתן לעריכה ישירה)
├── images/             # תיקיית 69 תמונות התערוכה בשמותיהן המקוריים בעברית
│   ├── אלון חנוך.jpg
│   ├── ברמן סילביה.jpg
│   └── ...
└── .gitignore          # סינון קבצים זמניים
```

## 🚀 פריסה (Deployment)

האתר בנוי ב-Vanilla HTML/CSS/JavaScript טהור ללא צורך ב-Build Step:
- **Vercel / Netlify / Cloudflare Pages:** פשוט מחברים את המאגר (Repository) ומגדירים את התיקייה הראשית.
- **GitHub Pages:** בהגדרות המאגר ב-GitHub: `Settings -> Pages -> Deploy from a branch -> main / (root)`.
- **מקומי:** ניתן לפתוח ישירות את `index.html` בכל דפדפן (כולל תמיכה מלאה ב-offline).

## ✏️ עדכון פרטים וסיפורים

כל הטקסטים, התאריכים והקישורים נשמרים בקובץ `data.json`.
בסביבת רשת (כמו Vercel או GitHub Pages), עריכה פשוטה של `data.json` תתעדכן באתר באופן מיידי ברענון הדף!
